# NumPy Learning Repository

This repository contains beginner-friendly NumPy practice files and assignment notebooks. It is organized as a hands-on learning project, with small Python scripts for individual concepts and notebooks for larger exercises.

## What This Repository Covers

- NumPy basics and why it is useful
- Creating 1D, 2D, and multi-dimensional arrays
- Array shape, size, dimensions, and data types
- Basic mathematical operations on arrays
- Indexing, slicing, and fancy indexing
- Filtering and reshaping arrays
- Flattening, stacking, and splitting arrays
- Common advanced operations such as insert, append, concatenate, and delete

## Project Structure

- `Basics.py`
  Introductory notes about NumPy and its use cases.

- `Array/`
  A set of numbered practice scripts covering topics step by step:
  - `1Array.py` - creating arrays
  - `2create_Array1.py`, `3create_Array2.py` - array creation methods
  - `4arrange.py` - arranging sequences
  - `5shape.py`, `6size.py`, `7ndim.py` - array properties
  - `8data_type.py` - data types
  - `9maths.py` - mathematical operations
  - `10Indexing_Slicing.py` - indexing and slicing
  - `11fancy_indexing.py` - fancy indexing
  - `12filtering.py` - filtering
  - `13Reshaping_Manupulating.py` - reshaping and manipulating arrays
  - `14Flattering.py` - flattening arrays
  - `15Advance_Numpy.py` - insert, append, concatenate, delete
  - `16Stacking_Array.py` - stacking arrays
  - `17Splitting_Array.py` - splitting arrays

- `assignment_1_solution_DS.ipynb`
  Assignment notebook for data science practice.

- `BCSE0593_Lab_2_Assignment_Solution_np.ipynb`
  NumPy lab assignment notebook.

## Requirements

- Python 3.x
- NumPy
- Jupyter Notebook or JupyterLab for `.ipynb` files

Install the main dependency with:

```bash
pip install numpy jupyter
```

## How To Run

Run any Python example file from the project root:

```bash
python Basics.py
python Array/1Array.py
python Array/15Advance_Numpy.py
```

To open the notebooks:

```bash
jupyter notebook
```

## Notes

- The repository is best suited for beginners who are learning NumPy step by step.
- Several inline explanations are written in a Hindi-English style, which may be helpful for quick revision.
- File names are numbered to reflect the learning order.

## Purpose

The goal of this repository is to build a practical understanding of NumPy through short examples and assignment-based learning.
